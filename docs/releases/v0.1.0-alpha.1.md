# v0.1.0-alpha.1 Closed Alpha

## 位置づけ

画像グリッド配置・透過クロップツール のクローズドアルファ版です。複数画像を読み込み、列数、行数、上下左右の余白、書き出し先の画像サイズを指定してグリッド上に配置する。余白、列幅、行高はハンドルで個別調整でき、ドラッグで固定アスペクト比のクロップ範囲を作り、透過情報を保ったままPNGやWebPへ書き出す。
